# 日语学习计划

状态：学习中

## 资料来源

- 《安宁日语：日语零基础入门训练营》讲义
- 《安宁日语零基础入门训练营》课后习题
- 《五十音图》书写与假名参考

这些资料作为学习与口语训练依据。资料整理不等于掌握；只有在能够脱离提示独立理解和表达后，才标记为“已学会”。

## 学习方式

参考英语学习仓库的方式，日语也采用：
1. 原课内容识别
2. 核心假名 / 词汇 / 语法锚点
3. 现实语境扩展
4. ChatGPT 真人角色对话练习
5. 错句与薄弱点记录
6. 独立复测
7. 达标后更新状态

## 当前阶段

先从零基础阶段开始：
- 五十音图
- 发音与书写
- 基础词汇
- 基础寒暄
- 自我介绍
- 地点、时间、人物、工作等日常表达

后续会逐步进入更完整的会话训练。
