## 训练原则

- 先听懂/读懂，再尝试自己说。
- 允许卡顿、说错、汉日混用。
- ChatGPT 先像真人一样理解并继续对话，不因小错误频繁打断。
- 一轮对话结束后，集中纠正表达、助词、词序、语气和发音重点。
- 同一表达在不同场景复现，检查是否能迁移使用。
- 只有脱离提示后能独立表达，才标记为“已学会”。

## 第一阶段：五十音图与基础发音

### 1. あ行：あいうえお / アイウエオ
学习重点：
- 元音 a / i / u / e / o
- 平假名与片假名对应
- 基本书写
- 音调概念

代表词：
- あい（愛）
- あう（会う）
- いう（言う）
- いえ（家）
- うえ（上）
- あお（青）
- あおい（青い）

### 2. か行：かきくけこ / カキクケコ

- あかい（赤い）
- き（木 / 気）

- いく（行く）

### 3. さ行：さしすせそ / サシスセソ

## ChatGPT 口语训练方式

后续可以直接把本仓库作为训练依据。典型训练流程：

1. ChatGPT 先选一个当前范围内的场景。
2. 只给必要背景，不给标准答案。
3. 用户用日语回答；不会时可以夹中文。
4. ChatGPT 先继续真人式交流。
5. 一轮结束后给出：
   - 用户原句
   - 可理解之处
   - 需要修正之处
   - 更自然表达
6. 下一轮换问法继续测试。
7. 将反复出现的错误写入错句记录。

## 推荐首批角色扮演场景

- 初次见面：姓名、国籍、职业、专业
- 便利店购物：これをください / いくらですか
- 问路：駅はどこですか
- 公司寒暄：お疲れ様です / お先に失礼します
- 自我介绍：私は〜です / 〜に勤めています
- 时间安排：何時ですか / 何曜日ですか
- 简单日常：今日何をしますか / 最近どうですか

### 1～3 课：江户时代的流行色・媚茶
主题：
- 颜色、语源、江户文化、和服底色
核心语法：
- ～っぽい：带有某种明显倾向/感觉
- ～めく：呈现出……的样子、带有……气息
文章表达：
- 黄色がかった濃い茶色
- といっても～
- ～といわれています
口语迁移：
- 子供っぽい / 忘れっぽい / 安っぽい
- 春めいてきました / 皮肉めいた言い方

### 4～6 课：秋天的七种花草・女郎花
主题：
- 秋七草、颜色、人物印象、传统文化
核心表达：
- ～げ：看起来……、给人……的感觉
- ～とは～ことだ：下定义
代表句型：
- 得意げにうなずく
- 怪しげな雰囲気
- 「女郎」とは～のことです
口语迁移：
- 不安げ / 自信ありげ / 寂しげ
- Xとは、～という意味です

### 7～9 课：夏天的问候・暑中見舞
主题：
- 暑中見舞、残暑見舞、梅雨、大正时期的问候习惯
核心语法：
- ～限り：只要……就……
- ～に限って：偏偏/越是某类人越……
- ～とは限らない：未必……
代表表达：
- 親と一緒にいる限り、安心していられる。
- 必ずしも～とは限らない。
- 遠方の相手に限らず、広く送られる。
口语迁移：
- 時間がある限り、続けます。
- 高いからといって、必ずしも良いとは限らない。

### 10～12 课：盖房子的不容易
主题：
- 建筑、照明、资金、心理体验、结果条件
核心语法：
- ～思いをする：经历某种心理感受
- 动词ます形 + 次第：一……马上……
- 名词 + 次第：取决于……
代表表达：
- 辛い思いをする
- わかり次第、ご報告します。
- 信じるか信じないかはあなた次第です。
- 建築でいえば～
口语迁移：
- 決まり次第、連絡します。
- 結果は努力次第です。
- 仕事でいえば、この部分が一番大変です。

### 13～14 课：雨水和农耕
主题：
- 二十四节气、七十二候、农耕、自然观察
核心语法：
- ～ものの：虽然……但是……
- ～ようとしない：没有要……的意思
- ～まいとして：为了不……
- ～ことから：从……可知/由于……
代表表达：
- 戦争で打撃を受けたものの～
- 人の話を聞こうとしない。
- 負担をかけまいとして～
- 行列ができていることから、人気のある店だとわかった。
口语迁移：
- 行こうと思ったものの、やめました。
- 彼は説明を聞こうとしません。
- 忘れまいとしてメモしました。
- 表情が明るいことから、安心しているとわかります。

## N2 练习册的使用方式

第 1～14 课练习可按以下顺序训练：
1. 汉字→假名
2. 假名→汉字
3. 日语词汇→中文
4. 助词/形式补全
5. 日语句子→中文理解
6. 中文→日语复述
7. 脱离讲义进行口头改写

判定标准：
- 只会认：仍为“学习中”
- 能按原句复述：仍不算完全掌握
- 能在新场景里独立替换主语、宾语、时态和语气：可进入“待复习/已学会”评估

## N2 口语优先级

- ～限り
- ～とは限らない
- ～次第
- ～ものの
- ～ようとしない

- ～っぽい
