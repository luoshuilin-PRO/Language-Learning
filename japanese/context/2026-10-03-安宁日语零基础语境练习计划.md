## 训练原则

- 先听懂/读懂，再尝试自己说。
- 允许卡顿、说错、汉日混用。
- ChatGPT 先像真人一样理解并继续对话，不因小错误频繁打断。
- 一轮对话结束后，集中纠正表达、助词、词序、语气和发音重点。
- 同一表达在不同场景复现，检查是否能迁移使用。
- 只有脱离提示后能独立表达，才标记为“已学会”。

## 第一阶段：五十音图与基础发音

### 1. あ行：あいうえお / アイウエオ
学习重点：
- 元音 a / i / u / e / o
- 平假名与片假名对应
- 基本书写
- 音调概念

代表词：
- あい（愛）
- あう（会う）
- いう（言う）
- いえ（家）
- うえ（上）
- あお（青）
- あおい（青い）

### 2. か行：かきくけこ / カキクケコ
代表词：
- あか（赤）
- あかい（赤い）
- き（木 / 気）
- えき（駅）
- あき（秋）
- あく（空く / 開く）
- おく（置く）
- いく（行く）
- きく（聞く / 聴く）
- かく（書く / 描く / 掻く）

### 3. さ行：さしすせそ / サシスセソ

### 4. た行：たちつてと / タチツテト

- ツ / ソ / シ 等易混片假名

## ChatGPT 口语训练方式

后续可以直接把本仓库作为训练依据。典型训练流程：

1. ChatGPT 先选一个当前范围内的场景。
2. 只给必要背景，不给标准答案。
3. 用户用日语回答；不会时可以夹中文。
4. ChatGPT 先继续真人式交流。
5. 一轮结束后给出：
   - 用户原句
   - 可理解之处
   - 需要修正之处
   - 更自然表达
6. 下一轮换问法继续测试。
7. 将反复出现的错误写入错句记录。

## 推荐首批角色扮演场景

- 初次见面：姓名、国籍、职业、专业
- 便利店购物：これをください / いくらですか
- 问路：駅はどこですか
- 公司寒暄：お疲れ様です / お先に失礼します
- 自我介绍：私は〜です / 〜に勤めています
- 时间安排：何時ですか / 何曜日ですか
- 简单日常：今日何をしますか / 最近どうですか
